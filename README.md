# Job Agent

A personal assistant for automated job searching and intelligent evaluation of job listings from the Swiss job portal [jobs.ch](https://www.jobs.ch).

## Features

- **Paginated Scraping**: Automated fetching of job listings from the `jobs.ch` internal API with multi-page support (`&start=` pagination).
- **Smart Stop Conditions**:
  - `last_known_job_url` — incremental bookmark; scraper stops as soon as it reaches the last previously seen job, avoiding re-processing old listings.
  - `max_scrape_limit` — hard cap on the number of new jobs saved per run.
  - Empty page detection — stops automatically when the API returns no more results.
- **Full Description Enrichment**: Each new job listing is enriched with full job description extracted from the detail page via JSON-LD (`application/ld+json`).
- **AI Evaluation**: Integration with Google Gemini API to match job descriptions against a structured candidate profile. Jobs scored below `min_ai_score` are automatically deleted.
- **Database**: Persistent storage of job listings in PostgreSQL including AI evaluation results (score, reasoning, strengths, missing skills, recommendation).
- **Settings UI**: Web-based settings page to manage all configuration keys (search term, AI score threshold, scrape limit, etc.) without restarting the app.
- **CV Profile Generation**: Upload a PDF CV or enter free text; Gemini AI extracts a structured candidate profile (JSON) used for job matching.

## Tech Stack

- Java 17+
- Spring Boot 3
- Spring Data JPA & PostgreSQL
- Thymeleaf (server-side templates)
- Google Gemini API (via REST)
- Apache PDFBox (PDF text extraction)
- Jsoup (HTML parsing / JSON-LD extraction)
- Jackson (JSON parsing)

## Getting Started

1. Set up a PostgreSQL database named `job_agent`.
2. Obtain a Gemini API key from [Google AI Studio](https://aistudio.google.com/).
3. Create `src/main/resources/application-local.properties` and add your key:
   ```properties
   gemini.api.key=your_actual_api_key_here
   ```
4. Run the application with the `local` profile:
   ```bash
   ./mvnw spring-boot:run -Dspring-boot.run.profiles=local
   ```
5. Open [http://localhost:8080](http://localhost:8080) in your browser.

## Configuration (via Settings UI)

All settings are stored in the `app_config` table and editable at `/settings`:

| Key | Default | Description |
|-----|---------|-------------|
| `search_term` | `java bern` | Search query sent to the jobs.ch API |
| `min_ai_score` | `40` | Jobs below this score are deleted after evaluation |
| `max_scrape_limit` | `80` | Max number of new jobs to save per scrape run |
| `last_known_job_url` | *(empty)* | URL of the most recently scraped job (auto-updated) |
| `cv_text` | *(default)* | Free-text candidate description used for AI matching |
| `cv_json` | *(default)* | Structured candidate profile JSON (auto-generated by AI) |

## API Endpoints

- `POST /api/jobs/scrape` — Triggers paginated scrape using `search_term` from config.
- `POST /api/jobs/evaluate` — Evaluates all unevaluated jobs using Gemini AI.
- `GET /api/jobs` — Retrieves all job listings.
- `PUT /api/config/{key}` — Updates a configuration value (used by the Settings UI).
- `POST /api/config/generate-profile` — Generates a structured candidate profile from CV text/PDF.
